# 開発ガイド

## 概要

「翠灯の迷宮」は、ブラウザで動く一人用のダンジョン RPG です。HTML・CSS・JavaScript の ES モジュールで構成され、実行時の外部ライブラリは使っていません。ゲームの遊び方と保存仕様は [README](../README.md) を参照してください。

## ローカルで表示する

Python が使える環境では、リポジトリのルートで次を実行し、`http://127.0.0.1:4173/` を開きます。

```sh
python -m http.server 4173 --bind 127.0.0.1
```

既存の `npm run dev` も開発用サーバーを起動しますが、`0.0.0.0` にバインドするため、同じネットワーク上からアクセスできる設定です。

## テストとビルド

```sh
npm test
npm run build
```

`npm test` は `tests/*.test.mjs` を Node.js の標準テストランナーで実行します。`npm run build` は `dist/` を作り直し、HTML・CSS・アイコン・`src/` の JavaScript・`assets/` をコピーします。`dist/` は生成物なので、修正は元ファイルに行ってください。

## 主な構成

- `index.html`、`style.css`：画面の構造と見た目。
- `src/app.js`：画面、入力、保存、音声などを結ぶエントリーポイント。
- `src/game.js`：ゲーム状態、行動、保存データのシリアライズと復元。
- `src/render.js`、`src/view.js`：迷宮と地図の描画、視点の動き。
- `src/audio.js`、`src/share.js`：音声と結果画像の共有。
- `assets/`：画面で使用する素材。
- `tests/`：進行、保存復元、描画関連、共有などの回帰テスト。

## 変更時の確認

保存はブラウザの `localStorage` を使います。保存形式を変える場合は、既存データの復元と旧形式との互換性を確認してください。音声は初期状態でオフです。操作を変える場合は画面ボタンとキーボード操作の両方を確認してください。

テストに加え、開始・同行者選択・探索・戦闘・帰還・再読み込み後の再開・結果画像の表示をブラウザで確認してください。素材を追加する場合は利用権を確認してください。
