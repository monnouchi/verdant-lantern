# 翠灯の迷宮

**[ブラウザで遊ぶ](https://monnouchi.github.io/verdant-lantern/)** — インストール不要。

同行者ひとりと10層の地下庭を探索する、一人用ダンジョンRPGです。最深部で「灯草の種」を入手し、町へ帰還するとクリアです。

## 操作

「森へ足を踏み入れる」から同行者を選んで開始します。同行者は探索途中に変更できません。

| 操作 | 画面ボタン | PCのキー |
| --- | --- | --- |
| 前進 / 後退 | △ / ▽ | ↑・↓ / W・S |
| 左右へ回転 | 左右のボタン | ←・→ / A・D |
| 攻撃 / 技 / 防御 | 戦闘中の各ボタン | 1 / 2 / 3 |

薬・逃走・帰還は画面のボタンで操作します。小さな地図を押すと拡大できます。画面が切り替わったら指やキーを離してから操作してください。

歩くと灯りを消費し、灯りが0になると体力を失います。宝箱・泉・休憩所で補給しながら進みましょう。戦闘中以外は「帰路の灯」で帰還できます。体力が0になり救済の護符もなければ探索終了となり、戦利品は持ち帰れません。

## 音・保存・共有

音は初期OFFです。音ボタンで切り替えられます。

進行は同じURL・同じブラウザに自動保存され、「前の探索をつづける」から再開できます。端末間の同期はありません。保存できない場合は画面に表示されます。ブラウザの保存データを消すと進行も失われます。以前の3層セーブは3層の冒険として続けられます。

「前の冒険の記録」は新しい冒険を始めると上書きされます。結果画面の「スコア画像を共有」から画像保存・文章コピー・対応端末の共有機能を使えます。Xへの投稿時は保存画像を手動で添付してください。
